# 🕹️ cursor-arcade-games - Play classic games inside your editor

[![Download Games](https://img.shields.io/badge/Download-Release_Page-blue.svg)](https://github.com/Edger-Stoneheart/cursor-arcade-games)

## 🎮 About the project

This collection brings classic arcade games to your coding environment. You can play Snake, 2048, Blocks, and Minesweeper directly inside VS Code or Cursor. These games feature a clean, monochrome design. They help you take short mental breaks without leaving your workspace. The games run without extra software or complex setups.

## 📋 Features

*   **Four classic games:** Play Snake, 2048, Blocks, and Minesweeper.
*   **Monochrome style:** Use a simple visual layout that matches your editor theme.
*   **Keyboard controls:** Navigate and play using only your keyboard.
*   **No dependencies:** Run the games without installing external libraries or runtimes.
*   **Focus mode:** Clear the screen and play during your breaks.
*   **Extension support:** Works inside both VS Code and the Cursor editor.

## 🛠️ System requirements

*   **Windows 10 or 11:** The games run on standard Windows setups.
*   **VS Code or Cursor:** You need one of these two editors installed.
*   **Memory:** 50MB of free RAM is enough to run these games smoothly.
*   **Internet:** You only need a connection to download the extension file.

## 🚀 Installation steps

Follow these steps to add the games to your editor.

1.  Visit the [releases page](https://github.com/Edger-Stoneheart/cursor-arcade-games) to download the extension file.
2.  Look for the file ending in `.vsix`. Click it to save the file to your computer.
3.  Open VS Code or Cursor on your Windows machine.
4.  Press `Ctrl + Shift + X` to open the Extensions view.
5.  Click the three dots located at the top right of the sidebar.
6.  Select **Install from VSIX**.
7.  Find the file you saved earlier and select it.
8.  Wait for a notification showing that the extension installed successfully.

## 🕹️ How to play

Once installed, you can launch any game through the command palette.

1.  Press `Ctrl + Shift + P` to open the command palette.
2.  Type "arcade" into the search bar.
3.  Select the game you want to play from the list.
4.  The game will open in a new editor tab.
5.  Follow the on-screen instructions to start your session.

## ⌨️ Controls

Each game uses standard keys to ensure quick navigation.

### Snake
*   **Arrow keys:** Change the direction of the snake.
*   **Space:** Pause or resume the game.

### 2048
*   **Arrow keys:** Move the tiles on the grid.
*   **R key:** Reset the board if you want to start over.

### Blocks
*   **Left/Right arrows:** Move the paddle.
*   **Space:** Launch the ball.

### Minesweeper
*   **Arrow keys:** Move the cursor around the grid.
*   **Enter key:** Open a tile.
*   **F key:** Place a flag on a tile you suspect contains a mine.

## 💡 Tips for focus breaks

*   **Set a timer:** Limit your game time to five or ten minutes.
*   **Use full-screen mode:** Press `F11` to hide your editor toolbars and panels. This creates a distraction-free gaming window.
*   **Manage tabs:** Close the game tab when you finish your break to keep your workspace tidy.

## ⚙️ Updating the games

I update these games to fix bugs and improve performance. Check the [releases page](https://github.com/Edger-Stoneheart/cursor-arcade-games) every few weeks for new versions. If you find an issue, you can reinstall the latest `.vsix` file using the same steps from the installation section.

## ❓ Troubleshooting

*   **Extension not showing:** If you cannot find the games in the command palette, restart your editor completely.
*   **Performance issues:** Ensure you do not have dozens of other heavy extensions running at the same time. These games are light, but they share resources with your editor.
*   **Visual bugs:** If the grid looks distorted, try zooming in or out of your editor by pressing `Ctrl` and the `+` or `-` keys. This resets the canvas scale and fixes layout errors.
*   **Broken keys:** Check if you have other keyboard-mapping extensions installed. These sometimes block inputs from reaching the games. Disable those extensions temporarily to play.
